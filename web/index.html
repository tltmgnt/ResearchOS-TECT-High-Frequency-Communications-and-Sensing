METHOD & CONTEXT

Show the model boundary.

Educational flat-layer geometry

One constant virtual height, symmetric path geometry and a simplified secant relationship. No Earth curvature, ray tracing, multi-hop modes, absorption model, groundwave prediction or live ionospheric data is included.

Virtual height is not true height

Assumed vertical round-trip delays are converted using cτ/2. This is an apparent/virtual height convention. Timing-only uncertainty excludes model/environment errors; no signal detection or true-height inversion is performed.

Independent research workspace

This is not a P.533 or VOACAP implementation, a frequency recommendation, a reliability predictor, a validated prototype, or a DARPA-affiliated service. Calibrated experiments and independently checked models remain necessary.
