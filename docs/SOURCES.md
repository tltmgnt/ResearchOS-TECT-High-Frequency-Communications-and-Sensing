# Primary sources

Reviewed November 16, 2026.

- [ITU-R P.533, Method for prediction of HF circuit performance](https://www.itu.int/rec/R-REC-P.533/en): reference context for a full HF prediction methodology. This repository does not implement P.533.
- [NIST/NBS, Ionospheric Radio Propagation, Monograph 80](https://nvlpubs.nist.gov/nistpubs/Legacy/MONO/nbsmonograph80.pdf): primary theoretical context for the secant relationship and its assumptions. The repository uses an explicitly simplified flat-layer fixture.
- [NOAA/NCEI Vertical Incidence Soundings](https://www.ngdc.noaa.gov/stp/IONO/ionogram.html): context for ionograms, critical frequencies and the distinction between virtual and true height. No NOAA data service is connected here.
- [DARPA Strategic Technology Office](https://www.darpa.mil/about/offices/sto) and [opportunities](https://www.darpa.mil/work-with-us/opportunities): engagement context only; verify the applicable live notice before any submission.

All example heights, critical frequencies, noise levels, losses, delays and uncertainty values are synthetic fixtures, not DARPA requirements or environmental forecasts. Sources do not establish endorsement, novelty, eligibility or performance. Model equations and limitations are explicitly defined in MODEL.md.
