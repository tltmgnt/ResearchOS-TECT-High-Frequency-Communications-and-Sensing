# Contributing

Run `python -m unittest discover -s tests -v` and the README workflow. Preserve units, cutoff-screen semantics, separation of measurements from educational calculations, and explicit noise-bandwidth assumptions. New propagation models need parameter domains, equations/source revisions, independent reference benchmarks and validation/uncertainty evidence.

Do not describe a toy cutoff as a usable-frequency forecast, a reference margin as reliability, or virtual height as true layer height. Do not treat hashes or software tests as authenticity, novelty or scientific approval. Protect credentials and unpublished partner data. Submit focused pull requests with behavior and verification evidence.
